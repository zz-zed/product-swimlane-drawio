# Example prompt

Use `product-swimlane-drawio` to create an editable vertical swimlane diagram for this fictional workflow.

- Lanes from left to right: Requester, Portal, Reviewer, Record Store.
- Main path: start, prepare a request, submit it, review it, decide approval, store the approved record, notify the requester, end.
- If the review is not approved, return it to the review step for rework before deciding again.
- Use phases for Intake, Review, and Completion.
- Confirm the structure before generating files. Do not invent additional steps.
